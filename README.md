# AI Password Strength Analyzer

## About

AI Password Strength Analyzer is a Python-based application that evaluates password strength and provides security suggestions to help users create stronger passwords.

## Features

- Password strength checking
- Strength classification
- Security recommendations
- Password generator
- Password history
- Simple and user-friendly interface

## Technologies Used

- Python
- Tkinter

## Project Files

- `main.py` – Main application
- `checker.py` – Password strength checking
- `generator.py` – Password generation
- `ai_suggestion.py` – Security suggestions

## How to Run

1. Install Python 3.x.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python main.py
